 Biografando – Ronaldo Fenômeno

 Sobre o projeto

O Biografando – Ronaldo Fenômeno é um projeto desenvolvido para apresentar a trajetória de Ronaldo Luís Nazário de Lima, um dos maiores jogadores da história do futebol mundial.

O site apresenta informações sobre sua carreira profissional, clubes pelos quais passou, conquistas e sua importância para o futebol brasileiro.

 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

 Funcionalidades

- Apresentação da biografia de Ronaldo Fenômeno.
- Layout organizado e estilizado.
- Imagem ilustrativa do jogador.
- Botão interativo com acesso ao Instagram oficial de Ronaldo.

 Objetivo

Desenvolver uma página web informativa, aplicando conhecimentos de HTML, CSS e JavaScript na construção de um projeto simples e interativo.

 Desenvolvedor

Projeto desenvolvido por Guilherme.

 Categoria
Projeto de desenvolvimento web e prática de programação front-end.



Para que serve o Git e o GitHub?

1. O que é Git?

O Git é um sistema de controle de versão utilizado por programadores para acompanhar e registrar as alterações feitas em um projeto. Ele permite recuperar versões anteriores, organizar o desenvolvimento e acompanhar o histórico do código.

Principais funções:

- Registrar alterações no código.
- Recuperar versões anteriores.
- Organizar o desenvolvimento.
- Facilitar o trabalho em equipe.

2. O que é GitHub?

O GitHub é uma plataforma online que permite armazenar, compartilhar e colaborar em projetos de programação. Ele utiliza o Git para gerenciar as versões dos arquivos.

Principais funções:

- Armazenar projetos na internet.
- Compartilhar códigos com outras pessoas.
- Trabalhar em equipe.
- Criar portfólios de programação.
- Acompanhar alterações nos projetos.
